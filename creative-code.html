Grammars-based Star Wars Crawler

This is a Star Wars opening crawl generator, complete with Glup Shittos, nostalgia farming, and random Dune references. The results are often silly, sometimes oddly compelling, and always Star Wars-y. This experiment builds off of Adam Smith's Glitch game, bad-quests.

Technical

For the text of the main body, this generator uses a template based on A New Hope's opening crawl, and for the titles, it randomly chooses a template from an array of templates modeled after the nine films' titles.

The generator uses a replacer() function to randomly fill dynamic slots with words from a filler() bank. For static slots, the generator uses a setter() function with an additional map check so repeated names, factions, and pronouns stay consistent throughout a generated crawl.

Title generation uses the same core functions, then checks the word count and may prepend "THE" so the results better resemble the naming patterns of the films. The crawl animation itself uses p5.js transforms to tilt, translate, and raise the generated text.

Reflection

This was my first time working with grammars, and for such a simple concept I found myself getting really excited about the potency of grammars-based generation. I'm happy with the variety of outputs, and I think that, due to the OOP-ness of the generator itself, it will be easy to expand the generator to further increase the variety of outputs.

One thing that irks me about the generator is that it can sometimes feel a bit too random. I'd prefer it if things like the galaxy's starting state and end state felt more related. A next iteration could use mappings or sub-keys to guide output more precisely, along with synonym handling for repeated static slots.

Lastly, I'd like to add a star field, film grain, and generative music to get this thing Star Wars-maxxed.

Wetlands through the Window

Twice a week, I take the Capitol Corridor train to get between Sacramento and San Jose, and twice a week I watch raptly as we pass through Suisun marsh, a lovely stretch of landscape between Suisun and Martinez. It's a beautiful view no matter the weather, but I particularly love it when the water is like a mirror to the sky above. For this experiment, I wanted to try to capture this, my favorite part of a long commute, in procedural perpetuity with an infinite scroll.

Technical

This experiment uses p5.js' native noise() functionality for marsh, sky, and hill generation. The marsh grass colors were approximated by eye and later refined with an inspired palette. The trees are rendered with triangle primitives. The hillside is a polygon generated using vertex calls with Perlin noise values, while the sky and marshlands are generated using Perlin noise and filled color regions.

The forced perspective effects on the sky and marsh are achieved by scaling their noise outputs along the y-axis. The marsh and hills infinitely scroll to emulate looking out a window on a train ride.

Reflection

I'm very happy with how this turned out. I wanted to make something that felt like I was perpetually passing through my favorite part of my bi-weekly commute, and I achieved that. The style and texturizing I added toward the end made it look like something I might sit down and paint in Photoshop.

Although I've worked with noise generation before, I pushed the limits of my own understanding of the technique and applied it in different ways for the sky, hills, and marsh. One place the code still needs improvement is efficiency; the original version is slow to load and resizing is buggy.

Dungeon + Overworld Generator

Two procedural world-generation approaches in one experiment: binary space partitioning for dungeons and Perlin noise for an overworld, rendered with a compact pixel tileset.

Technical

Dungeons: binary space partitioning. Overworld: Perlin noise.

Reflection

In the future, I'd like to add decor items using lazy flood fill generated biomes in the overworld, and I'd like to make the dungeons more interesting. I am happy with the data structure that I used to control each world's generation, though, and I think it will make future iterations simpler.

Generative Voronoi

I wanted to figure out how to generate a Voronoi diagram, so I started with that in mind and adjusted my photo inspiration to come from the results of my experimentation.

Technical

I used d3-delaunay to generate a Voronoi diagram, then did some minor Lloyd relaxation to normalize the polygons. To add polygons on scroll, click, or drag, I add to a global points array and regenerate the polygons with the updated array.

Evolutionary Impressions

Partner coded with Jackie Sanchez. This experiment explores image-based evolution using p5.js. Starting from an inspiration image, the program samples average colors in random regions and draws basic shapes, rectangles and ellipses, to slowly recreate the image through generative mutation. We collaborated on the initial framework, which included capturing average color from localized regions, then expanded the system to support more shapes and increased their number to improve coverage.

Technical

To keep color accuracy over time, the program re-samples colors every roughly 20 frames, avoiding performance hits while preventing drift. I also implemented an adaptive mutation rate that mimics the manual slider adjustments I was making: it starts slow, spikes briefly, then eases back, automated through counters and conditionals based on scoring performance.

Toward the end, I started noticing gaps in the final compositions, areas the shapes weren't reaching. Doubling the shapes helped, tripling helped more, but a true fix would require a preprocessing pass to identify large structural regions in the source image, like Jupiter's bands or an aurora.

Reflection

Overall, I'm happy with the results. The system produces visually interesting approximations, and the code is modular enough to iterate on. It's been a fun dive into mutation-based aesthetics, and there's plenty of room to evolve it further.
